# Traceroute утилита

Реализация утилиты traceroute на Python с поддержкой IPv4/IPv6 и ICMP/UDP/TCP, whois для AS.

## Возможности

- ✅ IPv4 и IPv6
- ✅ ICMP, UDP, TCP (SYN)
- ✅ Whois/AS для каждого IP (`-v`)
- ✅ N запросов на хоп (`-q`, по умолчанию 3) и интервал (`-i`)
- ✅ Таймаут (`-t`), максимальный TTL (`-n`)
- ✅ Размер пакета (`-s`, по умолчанию 40 байт)
- ✅ Порты для TCP/UDP (`-p`)

## Требования

- Python 3.10+
- scapy
- Права администратора/ sudo (для raw socket)
- Операционная система: Windows, Linux, macOS

## Установка

```bash
git clone <repository>
cd traceroute
```

Дополнительные зависимости не требуются - используются только встроенные модули Python.

## Использование

### Базовое использование

```bash
python main.py google.com           # по умолчанию icmp
python main.py google.com icmp      # явно ICMP
```

### Расширенные опции

```bash
# Указать максимальное количество переходов
python main.py -n 20 google.com

# Изменить количество запросов на каждый переход
python main.py -q 5 google.com

# Установить таймаут ожидания (в секундах)
python main.py -t 3 google.com

# Изменить размер пакета
python main.py -s 64 google.com

# Установить интервал между запросами
python main.py -i 0.5 google.com

# Комбинированный пример
python main.py -n 20 -q 5 -t 3 -s 64 -i 0.2 ya.ru

# TCP SYN
python main.py -p 443 8.8.8.8 tcp

# UDP
python main.py -p 53 1.1.1.1 udp
```

### Параметры командной строки

| Параметр | Короткий | Описание | По умолчанию |
|----------|----------|----------|--------------|
| Параметр | Короткий | Описание | По умолчанию |
|----------|----------|----------|--------------|
| `destination` | - | Целевой хост (IP или доменное имя) | - |
| `protocol` | - | `tcp` \| `udp` \| `icmp` | `icmp` |
| `--timeout` | `-t` | Таймаут ожидания ответа (сек) | 2.0 |
| `--port` | `-p` | Порт (TCP/UDP) | TCP:80 / UDP:33434 |
| `--max-requests` | `-n` | Максимальное число хопов (TTL) | 30 |
| `--queries` | `-q` | Количество запросов на хоп | 3 |
| `--interval` | `-i` | Интервал между запросами (сек) | 0.1 |
| `--packet-size` | `-s` | Размер пакета (байт) | 40 |
| `--asn` | `-v` | Вывод номера AS через whois | выкл |

## Права доступа

### Windows
Запустите командную строку от имени администратора:
```cmd
# Запуск от имени администратора
python main.py google.com
```

### Linux/macOS
Используйте sudo:
```bash
sudo python3 main.py google.com
```
